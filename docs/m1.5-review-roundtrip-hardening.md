# M1.5 translation quality and review roundtrip hardening

M1.5 fixes the remaining placeholder-related review failure without changing the original
video or repeating expensive OCR. It also makes glossary and pipeline revisions cheap to
review against already analyzed videos.

## Failure reproduced

The remaining M1.4 review item was scene 19 at 91.9375-125.9375 seconds:

- OCR source: `[실]LangGraph기초`
- prior normalized source: `[실] LangGraph 기초`
- prior target: `トップ > トップ > ターミン1`
- flags: missing placeholders and missing `LangGraph` / `基礎`

Direct M2M100 probes showed that changing only the placeholder spelling was unsafe:

| Probe form | Observed behavior |
| --- | --- |
| `<TERM0>` | Tokens were translated or duplicated |
| `[[TERM0]]` | Repeated star glyphs |
| `__TERM0__` | Repeated star glyphs |
| alphabetic sentinel | Extra Japanese title text was introduced |
| private-use sentinel | `<unk>` tokens |
| unprotected source | Technical terms could be translated instead of preserved |

A second experiment translated the non-glossary spans of 120 real protected strings
independently. It fixed short labels but damaged particles and sentence context in longer
Korean text, so global segmented translation was rejected.

## Conservative design

The implemented path keeps full-sentence M2M100 translation for mixed Korean sentences and
uses deterministic restoration only when no unprotected Hangul remains.

1. The glossary maps bracketed OCR shorthand `[실]` to canonical `[실습]` and target
   `[演習]`.
2. Alias replacement does not match an alias inside its already-canonical source. This prevents
   `Azure OpenA` from turning `Azure OpenAI` into `Azure OpenAII`, and applies the same
   protection to `OpenAI AP` / `OpenAI API`.
3. Labels such as `[실습] LangGraph 기초` become
   `[演習] LangGraph 基礎` without calling M2M100. Technical English, numbers, and punctuation
   remain unchanged.
4. Existing translations are reused only when the translation provider and normalized source
   match and the current glossary-aware quality checks pass. Deterministic labels are always
   regenerated so terms such as `Tool Calling` and `AgentExecutor` stay consistent.
5. When the glossary fingerprint or translation-analysis revision changes, matching schema-v2
   OCR regions are reconstructed from `regions.json`. The input image, OCR provider, ROI,
   exclusions, grouping, minimum height, and batch size must still match.
6. PaddleOCR and M2M100 now load their heavy runtime objects only on the first actual inference.
   A pure resume or glossary-only relocalization does not initialize either model.

Per-scene metrics distinguish current inference from retained provenance:

- `ocr_latency_ms`: OCR spent in the current run;
- `source_ocr_latency_ms`: original OCR latency retained across relocalization;
- `ocr_reused`: whether stored OCR geometry was used;
- `translation_reused`: per-region prior translation reuse;
- `translation_reused_count` and `analysis_relocalized_count`: aggregate review-loop metrics.

## Workflow

The normal command automatically chooses strict resume, stored-OCR relocalization, or full
analysis:

```powershell
text-localizer localize-video data\input\0.mp4 `
  --profile config\profiles\browser-lecture.yaml `
  --work-dir data\work\0-m13-timeline `
  --output data\output\0-m13-timeline `
  --sample-interval 1 `
  --boundary-refinement-iterations 3
```

Review `editor.html`, export edited JSON when manual changes are needed, then validate and
regenerate the browser artifacts:

```powershell
text-localizer render-tracks data\output\0-m13-timeline\tracks.json `
  --output data\output\0-m15-reviewed
```

The earlier migration pass from M1.4 corrected the alias-affected mixed Korean regions in two
M2M100 batches (55.073 seconds of CPU translation) while still reusing all OCR. After those
results were valid, the final v2 pass required no model inference.

The former scene-19 failure now produces `[演習] LangGraph 基礎`. Other deterministic
labels preserve technical identifiers, for example
`[演習] Tool Calling & AgentExecutor`.

Generated inputs, OCR data, frames, caches, models, HTML, and manifests remain ignored by Git.
Final burned-in or muxed MP4 rendering remains M2 scope.
