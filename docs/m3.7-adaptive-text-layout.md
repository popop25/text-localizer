# M3.7 adaptive text layout

M3.7 makes translated Japanese look like replacement UI text instead of a subtitle squeezed into
an OCR rectangle. It fixes two separate causes of the reported mismatch:

1. `source-palette-v2` estimates text height from the 80th-percentile vertical span of foreground
   columns, so a tall leading icon or bullet no longer determines the font size;
2. `adaptive-fit-v1` keeps the source row structure and fits the translation in a deterministic,
   auditable order without silently clipping it.

## Fit policy

For every approved schema-v2 region track, `layout-regions` uses Yu Gothic metrics and tries:

1. the inferred source size in the original box;
2. left-anchored horizontal expansion, normally capped at 1.8 times the source width and 60% of
   the video width;
3. a one-line font reduction, never below 80% of the inferred source size;
4. at most two lines only when the one-line policy cannot fit;
5. an explicit `layout_needs_review` result instead of hidden overflow when the normal policy is
   insufficient.

The viewer applies the persisted line breaks, normalized padding, font size, and box extensions to
every interpolated region keyframe. It then measures the real DOM box and uses a bounded binary fit
for small browser-font differences. Remaining overflow is shown with a visible review outline and
is not silently clipped.

## Run

Re-estimate style after this change, then build the final layout plan:

```powershell
text-localizer style-regions `
  data\output\0-m36-translation-quality\tracks.json `
  --output data\output\0-m37-font-calibrated `
  --work-dir data\work\0-m35-adaptive-style

text-localizer layout-regions `
  data\output\0-m37-font-calibrated\tracks.json `
  --output data\output\0-m37-adaptive-layout `
  --require-pass
```

`layout-regions` writes `tracks.json`, `viewer.html`, and `layout-quality.json`. It loads no OCR or
translation model and does not modify the source MP4.

include the title from 36.1px to 28.7px, the long instructor detail from 22.8px to 15.0px, and the
prerequisite line from 28.5px to 16.5px.

scroll transition frames remain governed by the existing temporal keyframes and benchmark.

## Scope boundary

This milestone corrects source-size inference and per-region text fitting. It does not infer the
exact web font family, reconstruct textured backgrounds, or solve translation wording. Layout is
invalidated by `retranslate-tracks` and must be regenerated after text changes.
