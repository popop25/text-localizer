# M1.1 static quality hardening

## Goal

M1.1 improves Korean screen-text localization quality before temporal tracking starts. It
keeps PaddleOCR and `facebook/m2m100_418M`, but makes the text passed to the translator
cleaner, more contextual, and auditable.

## Data flow

1. Crop an optional normalized region of interest (ROI) before OCR.
2. Remap crop-relative OCR polygons back to the original image coordinates.
3. Retain excluded and undersized regions as `ignore` records for auditability.
4. Conservatively join adjacent OCR boxes on the same line.
5. Normalize script-boundary spacing and configured OCR aliases.
6. Replace glossary terms with `<TERMn>` placeholders before translation.
7. Translate uncached strings in CPU batches and restore glossary targets afterward.
8. Flag suspicious translations instead of silently accepting them.
9. Render overlays against the unchanged source image.

ROI and exclusion boxes use `x,y,width,height`, normalized from 0 to 1 against the full
source image. An ROI reduces the pixels sent to OCR. An exclusion box is applied after OCR
and is useful for content inside the ROI that should remain untouched.

## CLI surface

`analyze-image` adds these options:

- `--roi x,y,width,height`: crop the image before OCR;
- `--exclude-roi x,y,width,height`: mark centered OCR regions as ignored; repeatable;
- `--min-region-height value`: ignore smaller regions while retaining them in JSON;
- `--glossary path`: load OCR aliases and Korean-to-Japanese protected terms;
- `--translation-batch-size value`: batch uncached translation inputs; default 4;
- `--no-group-adjacent`: disable conservative same-line grouping.

## Output schema v2

Each region retains the raw OCR text and adds:

- `source_text`: normalized text used as the cache key;
- `normalization_edits`: auditable alias and spacing changes;
- `group_member_count`: number of OCR boxes represented by the region;
- `action_reason`: classification or exclusion reason;
- `translation_quality_flags` and `needs_review`.

Run-level output records the applied analysis options, glossary fingerprint, batch count,
glossary hit count, and review count. A pipeline cache revision and the glossary fingerprint
are part of the translation cache namespace, so changing translation preparation logic or
glossary content does not silently reuse stale translations.

## Quality flags

M1.1 flags:

- a glossary placeholder or target lost during translation;
- Hangul left in Japanese output;
- an alphanumeric or Japanese fragment repeated at least three times;
- output that is suspiciously short relative to a non-trivial source.

These flags catch obvious failures but do not replace human review of meaning or style.

## Measured sample

The Korean lecture sample frame at 1920x1080 produced these Windows CPU measurements:

| Variant | OCR | Translation | Total | Peak process memory |
| --- | ---: | ---: | ---: | ---: |
| M1 full screen, cold | 60.6 s | 210.6 s | 273.3 s | 2.82 GB |
| M1.1 content ROI, cold | 32.1 s | 49.9 s | 82.8 s | 3.06 GB |
| M1.1 content ROI, cached | 33.1 s | 0.0 s | 33.5 s | 1.05 GB |

The M1.1 cold run detected 22 auditable regions, translated 15 content regions, excluded
four presenter-profile regions, applied 31 glossary terms, and produced zero automated
review flags. Batch size 4 was retained because batch size 8 raised peak memory to about
3.41 GB without enough benefit for this CPU-first baseline.

## Known limitations and next step

- ROI and exclusions are manually supplied per video; an editable saved profile is not yet
  implemented.
- Korean word-boundary recovery is glossary-assisted rather than a general morphological
  correction system.
- Long single-line overlays can become small because preview rendering still fits text into
  the original OCR box.
- Automated flags cannot detect every fluent but incomplete translation.
- Full-video scene detection, ROI hashing, track generation, and synchronized playback stay
  outside M1.1.

The next milestone should save an ROI profile and use ROI-only frame hashes to skip OCR on
unchanged scenes before building temporal tracks.
