# M3.8 visual replacement fidelity

M3.8 changes the acceptance target from "the Japanese string fits inside a planned box" to
"the Korean source pixels are covered and the Japanese replacement follows the same visual
element." The original video remains unchanged.

## User-visible failure

At `76.000` seconds in `0.mp4`, slow scrolling moves the lecture content while the M3.7
viewer continues to hold the `64.9375`-second OCR boxes. The instructor name, introduction,
learning objectives, and curriculum translations therefore appear below the Korean source.
M3.7's layout gates still pass because they measure translated-text clipping, not source-text
replacement.

The checked-in `config/benchmarks/0-replacement-quality.json` benchmark records six
human-audited source-pixel envelopes at this timestamp. The unmodified M3.7 result measures:

- minimum source-box IoU: `0.0000`;
- median source-box IoU: `0.0624`;
- minimum source coverage: `0.0000`;
- frame pass rate: `0.0`.

## Motion refinement

`refine-region-motion` detects a conservative class of sparse scene-anchor segments:

- both endpoints are scene OCR observations;
- vertical movement is dominant and large enough to be meaningful;
- horizontal and vertical speed stay below configurable limits;
- region width and height remain similar.

Only these slow-drift segments change from `hold` to `linear`. Existing visual-event
interpolation is never overwritten. The M3.8 `0.mp4` run refines 45 segments across 19 region
tracks. This is a CPU-only, model-free post-processing step and does not make the input video
or profile part of the implementation.

## Two-phase replacement

`layout-regions` now writes `overlay_replacement` metadata for every approved schema-v2
region. The viewer uses the declared composite order:

1. erase the padded source box with an opaque source-matched background;
2. draw the translated text in a separate transparent node.

Separating erasure from translated-text layout prevents width expansion or font fitting from
reducing the area that covers the source. The current `padded-source-box-v1` algorithm is
appropriate for the flat lecture/browser surfaces in this profile. Non-uniform backgrounds
will require a later glyph-mask and local-background reconstruction algorithm.

## Replacement quality gate

`evaluate-replacement` evaluates schema-v2 tracks against audited frames without loading OCR
or translation models. It reports:

- active-region count error;
- expected-region recall;
- minimum and median source-box IoU;
- minimum source coverage by the erase geometry;
- translated target-box collisions;
- per-frame and overall pass status.

The first M3.8 result at `76.000` seconds measures:

- 6/6 expected regions matched;
- minimum source-box IoU: `0.5207`;
- median source-box IoU: `0.6176`;
- minimum source coverage: `0.9994`;
- active-region count error: `0`;
- overlay collision count: `0`;
- frame pass rate: `1.0`.

The existing temporal benchmark (6/6 annotations and 18/18 keyframes) and translation
benchmark (14/14 cases and 104/104 checks) continue to pass.

## Reproduction

```powershell
text-localizer refine-region-motion `
  data\output\0-m37-adaptive-layout\tracks.json `
  --output data\output\0-m38-motion

text-localizer layout-regions `
  data\output\0-m38-motion\tracks.json `
  --output data\output\0-m38-replacement-fidelity `
  --require-pass

text-localizer evaluate-replacement `
  data\output\0-m38-replacement-fidelity\tracks.json `
  config\benchmarks\0-replacement-quality.json `
  --output data\output\0-m38-replacement-fidelity\replacement-quality.json `
  --require-pass
```

## Remaining generalization gate

The code paths and benchmark schema are video-independent, but this milestone is not yet proof
of production-grade generality. Before calling the solution general-purpose, the same gates
must pass on at least two additional screen-recording videos without code changes. Profiles may
adjust ROI and exclusions. A non-uniform-background sample must additionally replace
`padded-source-box-v1` with glyph masking and background reconstruction.
