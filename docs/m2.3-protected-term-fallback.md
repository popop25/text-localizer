# M2.3 protected-term translation fallback

M2.3 removes the four manual review edits required by the M2.2 full-video run while keeping
the local translation path conservative. A failed protected-placeholder translation may be
retried once with canonical glossary terms visible to the model, but the retry is accepted
only when every existing quality check passes.

## Failure probes

M2.2 produced four automatic review flags because M2M100 omitted the protected `LangChain`
placeholder. Direct local probes showed that an unconditional unprotected retry was unsafe:

| Source shape | Unprotected result |
| --- | --- |
| Long Azure OpenAI and LangChain sentence | Preserved both terms and retained the sentence meaning |
| Repeated short LangChain objective, variant 1 | Transliterated LangChain as ラングチャイン |
| Repeated short LangChain objective, variant 2 | Produced a breadcrumb-like title and ラングチェーン |
| Repeated short LangChain objective, variant 3 | Added a breadcrumb prefix and transliterated LangChain |

The long sentence passed the existing Hangul, repetition, length, placeholder, and glossary
target checks. The three short labels still failed the exact `LangChain` target requirement
and were rejected.

## Conservative retry contract

The translation pipeline now follows this contract:

1. Translate the placeholder-protected source first, as before.
2. Retry the canonical normalized source only when the first result has a
   `missing_placeholder` or `missing_glossary_target` flag.
3. Run glossary restoration and every existing translation quality check against the retry.
4. Adopt and cache the retry only when it has zero flags.
5. Keep the original flagged result when the retry fails; it still requires human review.
6. Record `translation_fallback_attempted` and `translation_fallback_used` per region, plus
   attempted and accepted counts in scene and track metrics.
7. Use translation cache revision `m23-v1` so stored OCR is relocalized under the new policy
   without repeating OCR.

The recurring course objective is deterministic profile data rather than a general model
heuristic. The glossary maps the observed pre-spacing OCR variants of
`√ 주로쓰이는LangChain의핵심 요소이해` to
`✓ LangChainで主に使われる主要要素を理解する`. Matching the raw variants matters because
glossary aliases are resolved before Korean/Latin boundary spacing is restored.

## Remaining limitations

Zero automatic flags mean the configured structural checks passed; they do not prove perfect
Japanese meaning or style. The raw-source retry deliberately refuses partial repairs, and any
failed retry remains visible to the normal editor workflow. The recurring objective entry is
specific to this course profile. New layouts or OCR variants should add reviewed aliases rather
than weakening global glossary matching. Generated OCR data, caches, manifests, media, ASS,
reports, and QA frames remain ignored by Git.
