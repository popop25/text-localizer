# M3.0 temporal quality benchmark

M3.0 turns visible overlay drift into a reproducible quality gate before changing the
timeline architecture. It evaluates the existing schema-v1 scene tracks against a small,
human-audited benchmark without loading OCR or translation models.

## Scope

The benchmark measures five independent properties:

- annotation coverage over the expected visible interval;
- keyframe recall at audited timestamps;
- onset and offset error for annotations with lifecycle boundaries;
- normalized bounding-box intersection-over-union (IoU);
- internal flicker gaps between matching overlay observations.

The file config/benchmarks/0-temporal-quality.json contains only timestamps, normalized
boxes, text match rules, and video metadata. The source video, extracted frames, and
generated reports remain ignored.

Run the benchmark against a track manifest:

    text-localizer evaluate-timeline `
      data\output\0-m23-auto\tracks.json `
      config\benchmarks\0-temporal-quality.json `
      --output data\work\0-m30-temporal-quality.json

Add --require-pass in regression jobs that should return a non-zero status when any gate
fails. A baseline measurement intentionally omits it so that the complete failure report is
still written.

## Annotation model

Each annotation declares:

- an expected start and end time;
- a normalized source- or translated-text matcher;
- one or more expected keyframe boxes;
- whether onset and offset should be evaluated.

Text matching uses Unicode NFKC normalization, case folding, and whitespace removal. This
allows stable matching across harmless OCR spacing differences while keeping the benchmark
independent from generated region IDs. Only approved translated regions that would actually
be rendered are observations.

Annotations may set evaluate_boundaries to false when they describe an audited subsection
of a longer-lived element. This prevents a positional scroll benchmark from pretending that
its selected subsection is the element's true lifecycle.

## Initial gates

| Metric | Gate |
| --- | ---: |
| Annotation recall at 95% interval coverage | >= 95% |
| Keyframe recall | >= 95% |
| P95 absolute onset/offset error | <= 67 ms |
| Median keyframe bbox IoU | >= 0.75 |
| Internal flicker events | 0 |

The 67 ms boundary target is approximately two frames at 29.97 fps.

## Ground-truth method

The checked-in benchmark uses three complementary observations from the unchanged
175.275102-second 0.mp4:

1. the course title around the intro fade and first scroll, as a hard-transition check;
2. the static 강의소개 navigation label, as a no-motion control;
3. the LangChain 기초 curriculum item, as a long vertical-scroll track.

Exact source frames were extracted only under ignored data/work. The moving curriculum item
was visually checked and its vertical pixel location was independently confirmed by matching
the unchanged source-text crop:

| Timestamp | Source y position |
| ---: | ---: |
| 126.0 s | 656 px |
| 130.0-140.0 s | 580 px |
| 140.4 s | 500 px |
| 145.0-159.0 s | 413-415 px |

Coordinates were then normalized against the 1920x1080 source.

Ground-truth revision 2 corrects the original moving-row annotations, which had paired each
timestamp with the following scroll state. The correction was made only after opening the
exact 126.0, 130.0, 140.4, and 145.0-second source frames side by side. It changes the spatial
interpretation of already-matched observations but not the missing coverage after 140.3125
seconds.

## M2.3 baseline

Measured against the unedited automatic data/output/0-m23-auto/tracks.json:

| Metric | Result | Gate |
| --- | ---: | --- |
| Annotation recall | 66.67% | FAIL |
| Keyframe recall | 66.67% | FAIL |
| P95 boundary error | 37.5 ms | PASS |
| Median bbox IoU | 0.964 | PASS |
| Internal flicker events | 0 | PASS |

The hard transition and static navigation control both pass. The scrolling LangChain 기초
item covers only 35.08% of its audited interval. Four of eight keyframes have a matching
overlay; their geometry is accurate under ground-truth revision 2, but the overlay disappears
after 140.3125 seconds even though the source item remains visible.

This isolates the dominant defect: refined whole-scene boundaries are already sufficiently
precise for the audited hard transition, while individual text regions cannot move or remain
alive independently. M3.1 should remove browser playback-clock lag, and the following
milestones should introduce partial visual events and region-scoped text tracks.

## Validation

M3.0 is deterministic and model-free. Unit tests cover a perfect contiguous track, an
internal gap, a missing keyframe, spatial drift, disabled boundary evaluation, duplicate
annotation rejection, report persistence, and CLI gate failure.
