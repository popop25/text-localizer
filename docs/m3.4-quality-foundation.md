# M3.4 quality foundation

M3.4 makes region-track text and lifecycle decisions conservative enough to support the next
visual-style and translation-quality milestones. It fixes two defects observed in the real
`0.mp4` viewer: stale intro text surviving on the lecture page and single-frame OCR corruption
becoming the canonical source for an otherwise valid translation.

## Design

### Translation-anchored OCR consensus

Every region track computes a confidence-weighted medoid across its scene and visual-event OCR
keyframes. The observed consensus selects the nearest already-translated schema-v1 candidate.
The selected candidate's original source/translation pair stays canonical, while the raw medoid
is recorded as `text_consensus.observed_consensus_text` for diagnosis.

This distinction matters because repeated OCR errors are correlated. During the intro transition,
seven frames read `OpenAI` as `OpenAl`; a plain majority vote would therefore regress a correct
identifier. The v1 anchor preserves `Azure OpenAI & LangChain 실전`. It also restores the correct
`Rest API` and `JSON` candidates instead of the previous `YReSt AP` and `USON` variants.

Low agreement or weak similarity between the observed consensus and translated candidate still
sets an automatic review flag. Consensus never invokes the translation model.

### Event-backed lifecycle closure

OCR event observations now double as visibility samples. When an observation ROI covers at least
half of a track box, a matched track remains visible. Two consecutive trailing misses ending in a
stable post-event frame close the track at the first miss and discard later keyframes. Base scene
continuity is otherwise preserved, including text intentionally excluded from the static OCR mask.

On `0.mp4`, this changes the intro company-logo track from `5.1875-20.5625` seconds to
`5.1875-9.2` seconds. It is absent throughout the audited stable lecture-page interval from
10 to 20 seconds.

### Disjoint OCR windows

`track-regions` accepts repeatable `--include-window START:END` values. They are mutually exclusive
with `--start-seconds` and `--end-seconds`, validated as ordered non-overlapping intervals, and
serialized into the result manifest. This allows targeted lifecycle and scrolling audits without
OCRing unrelated events between them:

    text-localizer track-regions `
      data\output\0-m23-timeline\tracks.json `
      data\work\0-m32-visual-events\visual-events.json `
      --profile config\profiles\browser-lecture.yaml `
      --output data\output\0-m34-quality-foundation `
      --work-dir data\work\0-m33-region-tracks `
      --include-window 8:9.4 `
      --include-window 120:166.8

Per-frame OCR observations remain resumable. The first combined run added eight intro frames and
reused eleven existing scroll frames; a result-only regeneration reused all nineteen.

## Strengthened temporal benchmark

Ground-truth revision 3 adds three controls to the original three annotations:

- the company-logo translation must be absent from 10-20 seconds;
- the `Rest API` canonical source must remain available at three scroll timestamps;
- the `JSON` canonical source must remain available at the same timestamps.

An annotation with `expect_visible: false` reverses the coverage calculation: any matching visible
interval is a leak and a flicker event. Absence annotations omit keyframes and boundary evaluation.
The earlier scroll-only M3.3 output fails revision 3 solely because the company-logo track covers
the entire forbidden interval. The M3.4 combined result passes:

| Metric | M3.3 scroll-only under revision 3 | M3.4 | Gate |
| --- | ---: | ---: | ---: |
| Annotation recall | 83.33% | 100% | >=95% |
| Keyframe recall | 100% | 100% | >=95% |
| P95 boundary error | 37.5 ms | 37.5 ms | <=67 ms |
| Median bbox IoU | 1.000 | 0.969 | >=0.75 |
| Leak/flicker events | 1 | 0 | 0 |
| All gates | FAIL | PASS | PASS |

The final result contains 33 independent region tracks, adjusts two lifecycles, and changes four
canonical candidate selections. The nineteen observations contain 230 matched and 104 unmatched
OCR regions. The eight newly processed CPU frames took 247.513 seconds in the combined run; cached
regeneration took 1.985 seconds and made no OCR calls.

## Scope boundary

M3.4 establishes measurable text identity and visibility correctness. It does not yet infer source
font, size, foreground/background color, or improve Japanese phrasing with a stronger translation
model. M3.5 adds source-matched palette and size inference for the viewer; see
`m3.5-adaptive-overlay-style.md`. Japanese phrasing remains a separate follow-up milestone.
