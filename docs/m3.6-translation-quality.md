# M3.6 translation quality

## Goal

M3.6 improves Korean-to-Japanese lecture-text meaning without rerunning OCR, temporal tracking,
or adaptive styling. It replaces model-card assumptions with a repeatable benchmark over the
actual `0.mp4` lecture vocabulary.

The original video remains unchanged. Models and generated reports remain under ignored `models/`
and `data/` directories.

## Model decision

Three model families were considered:

- `facebook/m2m100_418M`: the existing MIT-licensed 418M multilingual provider;
- `facebook/nllb-200-distilled-600M`: excluded because its model card uses CC-BY-NC and states
  that the research model is not released for production deployment;
- `sappho192/gemma3-multilingual-translator-270m`: selected for measurement because its model card
  supports Korean, English, and Japanese in all directions, provides a 270M local checkpoint, and
  documents CPU-compatible Transformers inference.

Upstream references:

- https://huggingface.co/facebook/m2m100_418M
- https://huggingface.co/facebook/nllb-200-distilled-600M
- https://huggingface.co/sappho192/gemma3-multilingual-translator-270m

Model files are downloaded explicitly and are not redistributed. Review the upstream model and
base-model terms before using the artifacts outside this local project.

## Benchmark contract

`config/benchmarks/0-translation-quality.json` contains fourteen human-reviewed representative
source strings from the 33 canonical region tracks. Each case declares:

- required Japanese meaning or terminology;
- alternative acceptable expressions where natural variants are valid;
- forbidden observed mistranslations;
- ASCII technical terms that must be preserved;
- a Japanese reference used for a non-gating character-bigram similarity signal.

The hard gates require at least 90% case recall, 95% individual checks, no missing cases, no
forbidden mistranslations, and no remaining Hangul. The checked cases cover the course title,
overview, learning objectives, hands-on Agent implementation, curriculum, and prerequisites.

The glossary adds only reusable domain units rather than complete `0.mp4` answers:

- `실전 -> 実践`
- `활용법 -> 活用方法`
- `구현 -> 実装`
- `나만의 -> 自分だけの`
- `핵심 요소 이해 -> 主要要素を理解する`
- exact preservation of `AI Agent`

## Measured comparison

All model runs used Windows-native Python 3.12.9, CPU inference, the same glossary, batch size four,
and the same fourteen inputs. Three cases were resolved deterministically by the glossary and eleven
were sent to each model.

| Provider | Cases | Checks | Forbidden | Mean reference similarity | Model time |
| --- | ---: | ---: | ---: | ---: | ---: |
| M2M100 418M + glossary v2 | 8/14 | 89/104 | 4 | 0.7261 | 71.83 s |
| Gemma3 translator 270M + glossary v2 | 14/14 | 104/104 | 0 | 0.8833 | 43.26 s |

The 270M provider is therefore the default. M2M100 remains available through
`--translation-provider m2m100` for regression comparison.

## Commands

Prepare the default translation model explicitly:

```powershell
text-localizer setup-models --translation --models-root models
```

Benchmark either provider without OCR:

```powershell
text-localizer benchmark-translator `
  config\benchmarks\0-translation-quality.json `
  --translation-provider gemma3-270m `
  --models-root models `
  --output data\output\0-m36-translation-quality\gemma3-270m-glossary-v2.json
```

Retranslate an existing schema-v2 manifest while preserving geometry and style:

```powershell
text-localizer retranslate-tracks `
  data\output\0-m35-adaptive-style\tracks.json `
  --output data\output\0-m36-translation-quality `
  --translation-provider gemma3-270m `
  --models-root models
```

Run both quality gates:

```powershell
text-localizer evaluate-translations `
  data\output\0-m36-translation-quality\tracks.json `
  config\benchmarks\0-translation-quality.json `
  --require-pass

text-localizer evaluate-timeline `
  data\output\0-m36-translation-quality\tracks.json `
  config\benchmarks\0-temporal-quality.json `
  --require-pass
```

## `0.mp4` output

- viewer: `data/output/0-m36-translation-quality/viewer.html`
- tracks: `data/output/0-m36-translation-quality/tracks.json`
- translation report: `data/output/0-m36-translation-quality/translation-quality.json`
- temporal report: `data/output/0-m36-translation-quality/temporal-quality.json`

The real retranslation processed 33 region tracks from 32 unique source strings in 123.55 seconds.
It preserved all 33 overlay styles and every region keyframe. Translation quality passed all
14 cases and 104 checks. Temporal quality remained 6/6 annotations and 18/18 keyframes, with
37.5 ms P95 boundary error, 0.9689 median bbox IoU, and zero flicker.

One malformed OCR source, `[차고자ᄅ리ᄏ1`, remains flagged as `hangul_in_translation` and is hidden
by the viewer. It is intentionally not converted into a guessed Japanese string; resolving it
belongs to OCR/manual review rather than translation-model post-processing.
