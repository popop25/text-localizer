# M3.5 adaptive overlay style

M3.5 replaces the viewer's one-size-fits-all black subtitle box with a source-matched style for
each schema-v2 region track. The objective is visual language replacement: cover the original
Korean text with its surrounding screen color, then draw the Japanese text at a comparable size
and contrast.

## Pipeline

`style-regions` is a model-free stage after region tracking. It loads neither OCR nor translation:

1. select the highest-confidence stable keyframe for every region track;
2. extract each unique source frame with FFmpeg and cache it under a source-video fingerprint;
3. quantize the padding ring around the source bbox and select its dominant background cluster;
4. separate foreground pixels by color distance from that background;
5. estimate source foreground color, glyph-height-derived font size, weight, and WCAG contrast;
6. write a validated `overlay_style` object on the region track and regenerate `viewer.html`.

Run the real M3.4 result:

    text-localizer style-regions `
      data\output\0-m34-quality-foundation\tracks.json `
      --output data\output\0-m35-adaptive-style `
      --work-dir data\work\0-m35-adaptive-style

The output keeps all temporal geometry and translations unchanged. `tracks.json` adds
`region_styling` audit metadata and the viewer reads the style only when present, so earlier
schema-v2 manifests retain the fixed fallback behavior.

## Style contract

The style schema permits only bounded, validated fields: hexadecimal foreground/background
colors, opacity, normalized font size, numeric weight and line height, border radius, one of two
safe text-shadow values, contrast/confidence diagnostics, and a bounded fallback reason. It does
not accept arbitrary CSS.

High-confidence styles use an opaque sampled background so the Korean glyphs are actually covered,
not merely overlaid. When the foreground cannot be separated but the background is reliable, the
viewer keeps the sampled background and chooses black or white for maximum contrast. A fixed
black/white palette is reserved for low-confidence background estimates. Translation text starts
at the inferred source size and is reduced only when it would overflow the tracked box, with a
68-percent floor.

The unchanged 175.275102-second source was processed on Windows Python 3.12.9 and CPU only:

| Region tracks styled | 33 |

The dominant lecture-page background is correctly recovered near `#1d1d1d`; text colors remain
track-specific gray values instead of forced white. The title track, for example, uses background
`#1d1d1d`, foreground `#c9c9ca`, and a 0.0334-video-height font size.

## Scope boundary

This milestone infers palette, contrast, weight, and approximate size for the browser viewer. It
does not identify the exact source font family, reconstruct textured backgrounds, or burn schema-v2
styles into a final MP4. Japanese phrasing/model quality also remains a separate milestone so that
visual and semantic changes can be evaluated independently.
